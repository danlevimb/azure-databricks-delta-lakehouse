# Azure Databricks Delta Lakehouse

Portfolio-oriented Azure Databricks project demonstrating PySpark-based Bronze/Silver/Gold processing, Delta Lake tables, MERGE/upsert patterns, SCD Type 2 dimensional history, time travel validation, and data quality checks.

## Project Status

Technical MVP completed in Azure Databricks. Public documentation and evidence packaging are in progress.

## Core Capabilities

- Azure Databricks workspace usage
- PySpark notebooks
- ADLS Gen2 storage
- Delta Lake path-based tables
- Bronze / Silver / Gold Lakehouse architecture
- Silver data quality validation
- Rejected records handling
- Gold dimensional modeling
- SCD Type 2 customer dimension
- Delta MERGE / upsert
- Delta time travel validation
- Final data quality validation report
